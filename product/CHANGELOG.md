# 버전 기록

## 1.0.0 (2026-11)

### 납품 전 점검에서 보강한 것
- **어떤 화면이든**: 문서 안에 든 iframe(같은 도메인, 여러 겹) 안쪽까지 비교·표시·이동. doctype 없는 옛 화면(호환 모드) 지원. 숨긴 영역 빼기(`visibleOnly`)
- **보안**: `mountViewer` 주소 검사(같은 도메인 http/https 만, `javascript:` 거부). 한 장 보기는 원본 스크립트를 가져오지 않음
- **변경점으로 흘러가기**: 변경을 누르면 거리와 상관없이 천천히 출발해 빠르게 지나가고 천천히 도착 (0.4 ~ 0.8초). 수천 쪽 떨어져 있어도 같은 느낌이고 프레임이 고름. 도착하면 바로 반짝
- **속도**: 긴 문서 비교 계산 1.0초 → 0.4초(3,000쪽), 멀리 있는 변경으로 이동 2.3초 → 0.8초. 글자 표시를 고정형으로 바꿔 변경이 수천 건이어도 화면 고치기가 느려지지 않음
- **안정성**: 새 비교가 시작되면 앞 비교 취소, 백그라운드 계산 시간 제한·오류 시 자동 전환. 지문 96비트로 강화. 정리(destroy) 후 원본이 글자 하나까지 그대로
- **쓰기 쉽게**: 뼈대 함수 `mountLayout`, 쪽 건너뛰기 옵션 `virtualize`, 단축키 F7 은 초점이 든 비교 창만
- **자동 테스트**: 브라우저 테스트 15종(검사 121개) `npm run test:browser -w @silvergate/compare-dom`


첫 납품 버전.

- 그려진 화면 두 개(JSP·ASP·PHP·일반 HTML·Vue·React·Angular·웹 컴포넌트)를 원본 그대로 두고 비교·표시
- 색: 추가 초록 · 수정 파랑(넣은 글자 밑줄) · 삭제 빨강 취소선 · 이동 보라 (CSS 변수로 변경 가능)
- 좌우 높이 맞추기: 한쪽에만 있는 덩어리는 반대쪽에 같은 높이의 빈 칸, 수정으로 높이가 달라지면 여백
- 두 문서를 한 스크롤 영역에 나란히 (한 장처럼 함께 움직임). 영역을 나눌 수 없으면 스크롤 맞춤
- 표: 열 추가/삭제 한 건으로, 칸 병합(colspan·rowspan) 수정, 머리글 여러 단·묶음 칸을 눈에 보이는 격자 기준으로, 줄 자리 바꿈은 이동
- 쪽 문서: 쪽 경계 무시(내용끼리 비교), 보이는 쪽만 높이 맞춤 → 3,000쪽 약 3초, 화면 멈춤 0ms
- 변경 목록·집계·이전/다음(F7)·한 장 보기(redline)·부드러운 이동과 도착 후 반짝임
- 화면이 다시 그려지면 자동으로 다시 비교 (watch)
- 보안 정책(CSP): style nonce 옵션, Worker 가 막히면 자동으로 화면 쪽에서 계산
- 한국어·영어 문구
