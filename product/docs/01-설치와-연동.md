# 1. 설치와 연동

## 1-1. 어떤 방식을 쓸까

| 고객 화면 | 권장 방식 | 예제 |
|---|---|---|
| JSP·ASP·PHP 등 서버 화면, 이미 있는 화면 주소 두 개 (안에 iframe 이 또 있어도 됨) | `mountViewer` (iframe 두 개) | `examples/jsp` · `examples/plain-html/viewer.html` |
| 같은 페이지 안에 두 문서를 직접 그림 (일반 JS) | `mountLayout` + `createCompare` | `examples/plain-html/index.html` |
| Vue 3 | `@silvergate/compare-vue` 의 `<SgCompare>` | `examples/vue3` |
| React 17+ | `@silvergate/compare-react` 의 `<SgCompare>` | `examples/react` |
| Angular·Svelte·기타 | `createCompare` (`ngAfterViewInit` 등 그린 직후) | `examples/angular` |

## 1-2. 설치

**script 태그**: `dist/sg-compare.min.js` 를 웹 정적 폴더에 두고 `<script src>` 로 읽습니다. 전역 `window.SgCompare`.

**npm (인터넷 없이)**: 납품 폴더의 `packages/*.tgz` 를 프로젝트에 복사하고

```bash
npm install ./vendor/silvergate-compare-dom-1.0.0.tgz
npm install ./vendor/silvergate-compare-vue-1.0.0.tgz     # Vue 3
npm install ./vendor/silvergate-compare-react-1.0.0.tgz   # React
```

`package.json` 에 `"@silvergate/compare-dom": "file:vendor/silvergate-compare-dom-1.0.0.tgz"` 로 남으므로
다른 개발자·CI 도 같은 파일로 설치됩니다. 런타임 의존성이 없어 추가로 받는 패키지는 없습니다.
(vue/react 어댑터는 고객 프로젝트에 이미 있는 vue/react 를 그대로 씁니다.)

**사내 저장소(Nexus·Verdaccio)**: tgz 를 `npm publish ./silvergate-compare-dom-1.0.0.tgz --registry <사내 주소>` 로 올려 두면
일반 패키지처럼 `npm install @silvergate/compare-dom` 으로 씁니다.

## 1-3. 화면 뼈대

두 문서를 **한 스크롤 영역** 안에 나란히 두는 것이 가장 자연스럽습니다(좌우가 한 장처럼 움직임).
`mountViewer` 와 Vue/React 어댑터는 이 뼈대를 스스로 만듭니다. 직접 문서를 그릴 때는 `mountLayout` 이 뼈대를 만들어 줍니다:

```js
const lay = SgCompare.mountLayout(document.getElementById('viewer'), { leftLabel: 'v1.0', rightLabel: 'v1.1' });
lay.left.append(이전문서요소);
lay.right.append(새문서요소);
const ctrl = SgCompare.createCompare({ left: lay.left, right: lay.right, leftScroller: lay.desk, rightScroller: lay.desk, page: '.page', watch: true });
lay.attach(ctrl);
```

뼈대까지 고객사 디자인으로 직접 만들려면: 스크롤되는 요소 하나 안에 두 문서를 좌우로 놓고, 그 요소를 `leftScroller`·`rightScroller` 양쪽에 넘기면 됩니다 (`examples/angular` 참고).

기본 도구 막대·목록 대신 고객사 디자인으로 직접 만들려면 `ctrl.changes`, `ctrl.stats`, `ctrl.goTo(i)`, `ctrl.on('update')` 를 쓰세요 (`02-API.md`).

## 1-4. 정리

화면을 떠날 때 `ctrl.destroy()` (어댑터는 자동). 표시·빈 칸·감시가 모두 지워지고 원본 DOM 은 처음 그대로입니다.
