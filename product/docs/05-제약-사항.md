# 5. 제약 사항

| 항목 | 내용 · 대응 |
|---|---|
| 다른 도메인 화면 | 브라우저 보안상 iframe 안을 읽을 수 없음 → 리버스 프록시로 같은 도메인 아래 두기 |
| 가상 스크롤 화면 | 화면에 보이는 행만 DOM 에 있는 그리드(AG Grid 등)는 보이는 부분만 비교됨 → 비교 화면에서는 전체 렌더 또는 인쇄용 화면 사용 |
| canvas·이미지 속 글자 | 픽셀은 비교하지 않음. `<img>` 는 `src`·`alt` 변경으로 감지 |
| PDF 파일 자체 | 브라우저에 HTML 로 그려진 화면이 대상. PDF 는 HTML 변환 후 비교 |
| 아주 오래된 브라우저 | 글자 단위 색만 빠지고 나머지는 동작 (README 지원 브라우저 참고) |
| 문서 안의 iframe | 같은 도메인이면 안쪽 내용까지 비교 (여러 겹도). 다른 도메인 iframe 은 주소(src) 바뀜만 감지 |
| Shadow DOM | 열린(open) shadow root 는 안쪽까지 비교. 닫힌(closed) shadow root 는 브라우저가 막아 볼 수 없음 |
| 숨긴 영역 | 기본은 display:none 영역도 비교 (변경 목록에는 나오지만 화면에서 볼 수 없음). 빼려면 `visibleOnly: true` |
| CSS 로 만든 글자 | `::before`/`::after` 의 content, 자동 번호(counter)는 문서 내용이 아니라 비교하지 않음 |
