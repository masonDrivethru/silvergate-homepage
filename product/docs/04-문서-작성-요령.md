# 4. 정확도를 높이는 문서 작성 요령 (선택)

아무것도 하지 않아도 동작합니다. 아래를 지키면 더 정확해집니다.

1. **반복 항목에 고유 키** — 행·단계·원자재처럼 반복되는 덩어리에 `data-sgc-key="DB의 ID"`.
   순서가 바뀌면 '이동', 중간에 끼면 '추가'로 정확히 잡힙니다. (`data-key` 도 인식)
2. **매번 바뀌는 칸은 제외** — 출력일시·출력자·페이지 번호·워터마크에 `data-sgc-ignore` (또는 `ignore` 옵션 선택자).
3. **쪽 요소 표시** — 쪽마다 같은 클래스(예 `.page`)를 두고 `page: '.page'`. 변경 목록에 "n쪽"이 나오고, 높이 맞춤을 보이는 쪽만 합니다.
   **수백 쪽이 넘으면** 화면 CSS 에 아래 한 줄을 넣는 것을 강하게 권합니다. 화면 밖 쪽을 브라우저가 그리지 않아, 처음 그리는 시간과 스크롤이 크게 좋아집니다
   (쪽이 무거운 3,000쪽 문서 기준: 처음 그리기 7초 → 0.5초).

   ```css
   .page { content-visibility: auto; contain-intrinsic-size: auto 674px auto 1031px; }  /* 값 = padding 을 뺀 내용 상자 크기 */
   ```

   화면 CSS 를 고칠 수 없으면 옵션 `virtualize: true` 로 모듈이 대신 걸어 줍니다 (쪽 크기를 재서 넣고, 모양이 달라지면 스스로 되돌림).
   다만 이미 다 그려진 뒤에 거는 것이라 처음 그리는 시간은 줄지 않고, 쪽이 가벼운 문서에는 이득이 없습니다.
4. **표는 실제 `<table>`** — rowspan·colspan 병합, 열 추가/삭제, 행 이동을 표 구조로 이해합니다.
   div 로 만든 격자도 비교는 되지만 열 단위 인식은 안 됩니다.
5. **같은 글꼴·폭** — 좌우를 같은 너비로 그려야 높이 맞춤이 정확합니다. 웹폰트 로딩 후 자동으로 다시 맞춥니다.
